# Public research record instructions

Append a dated, disclosure-safe entry to `docs/RESEARCH_PROGRESS_LOG.md` whenever substantive project work produces a result. Preserve earlier entries, null results, and failures; make corrections through dated additions.

Credit published sources and distinguish their findings from this project's contributions. Label literature review, simulation, planned experiments, measured results, and independent replication accurately.

Follow the README disclosure boundary. Keep unpublished mathematics, blueprints, device parameters, raw measurements, patent-sensitive work, and enabling implementation details in the authorized private technical record. This public repository contains progress summaries and educational review material.

Do not invent daily activity or imply unattended research is running. The founder requested ongoing public/private logging on 2026-10-03.
